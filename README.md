## Help:

- `python -m venv venv`
- `source venv/bin/activate`
- `pip install -r requirements.txt`
- `python app.py`

After launch:

- Enter text or url.
- Enter the name of the final file.

1. A folder "qr_codes" will be created in which a file with the specified name will appear.
